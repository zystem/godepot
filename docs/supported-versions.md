# Supported versions

Reference. The rule is in [SECURITY.md](../SECURITY.md): the **latest release** gets security fixes; a release is supported until the next one is made.

| Release | Date | Status |
|---|---|---|
| **0.7.1** | 2026-11-28 | supported: the latest |
| 0.7.0, 0.6.0 | 2026-11-28, 2026-11-21 | not supported: update |

While godepot is before 1.0 a release may change settings and tables; [CHANGELOG.md](../CHANGELOG.md) says what to do. This page is updated by each release ([release.md](release.md)).
